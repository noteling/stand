# Context

Put Markdown or text files here. During a call, when Stand is asked something it does not know, it looks the answer up in these files and says it in its own words.

This README is not read. With nothing else here, and no other source, Stand has nothing to look up, and it will say it does not know.

Notes can also come from other folders on this Mac and from GitHub repositories. Add them in the app (the **Notes…** link in the panel) or list them under `"sources"` in `brain.json` at the repo root, which also says which model does the looking up and how it is reached. The main README has the details.
